# 核心指令自定义

设置中的“核心指令”提供主体、构图、风格、视角的两种表达，以及通用、陈列师的角色指令。模块与角色身份、图片发送范围、推理输出约束继续由程序管理。

## 编辑与预览

- 未自定义的项仅显示使用内置指令的状态，不展示出厂正文。启用自定义从空白开始；显式空字符串表示清空该项文字，取消自定义表示跟随默认。
- 每个模块的原生图文表达和文字加图片集合表达独立设置。预览仅构造当前项，用实际编译器展开占位符，模拟图片从 `image_1` 开始；不会引入当前工程的其他模块、出厂正文或隐藏占位。空白表达预览为空。视角支持试填角度。
- 角色只预览自己的文字，不将推理角色混入两组生图预览。
- 修改、恢复默认、导入只更新草稿；“保存并应用”后才写入运行配置并即时用于后续任务，无须重启。已有排队或执行中任务继续使用自己的快照，历史任务不重写。
- 修改角色会让使用该角色的自动提示词复用状态失效，不自动发起推理或生图。
- 离开设置或关闭程序时保护未应用草稿；Ctrl+S 保存当前指令设置。

## 恢复与导入导出

“恢复本项默认”移除当前模块或角色的覆盖，“全部恢复默认”清空全部覆盖。恢复的是当前程序版本的默认指令，不涉及工程、模型、密钥或其他设置。

JSON 文件只包含用户覆盖，具有独立格式版本和严格字段校验。导入为草稿，查看并保存后才应用；导出可包含当前草稿。未知模块、角色、字段、版本或非法模块占位符均拒绝，当前有效配置保留。用户可手动将导出文件带到开发版试用，选定内容再经开发审阅加入发布默认配置。

## 运行数据与旧工具兼容

新覆盖文件为 `prompt-customizations.v1.json`，与其他运行配置同目录：开发版 `.local/runtime`、安装版 `%APPDATA%/Ediro/runtime`、便携版程序旁 `data/.local/runtime`。三个位置分别保存，不互相同步。没有自定义的项跟随应用版本更新，自定义项保留。

首次使用兼容已有 `prompt-config.v1.json`：只将与当前发布默认不同的可编辑指令视为用户覆盖；原文件不改写。新文件存在后，对这四个模块的可编辑文字以新文件为准，避免恢复默认后旧工具配置重新生效。旧文件的模块名称和拼接格式仍保留。后续从旧 PromptTuner 写入旧文件不会覆盖新设置页管理的这些文字。

## 验证

核心与存储测试：`tests/prompt-customization.test.ts`、`tests/prompt-customization-repository.test.ts`。构建后可运行 `scripts/prompt-settings-desktop-smoke.cjs`，使用独立运行目录、真实 Electron 页面与 controller、模拟推理和禁止外网，验证保存、恢复、导入导出、角色生效、重启与两种窗口尺寸。测试不证明真实模型效果。
