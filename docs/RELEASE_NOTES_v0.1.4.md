# Ediro v0.1.4

本版本改进自动提示词、指令设置与局部编辑，并调整工程保存时机和生图失败诊断。

## 自动提示词与参考输入

- 推理与生成图片分开操作。生成始终使用当前提示词，用户自行决定是否重新推理。
- 自动提示词支持流式预览；完整成功后保存，失败或取消保留原正文。
- 主体、构图、风格和视角的额外要求统一交给自动提示词综合，避免旧要求在生成时重复附加。
- 改进参考图片与对应要求的传递，保留“图文 / 仅描述”的发送边界。
- 支持向当前参考模块直接粘贴剪贴板图片。

## 指令与模型设置

- 核心指令显示只读出厂默认内容，可从默认内容开始自定义。
- 模块生图指令、模块推理指令和角色指令支持独立预设、导入导出及恢复默认。
- 统一 Nano Banana 与 GPT Image 的型号识别、能力和默认参数设置；支持手动修正家族型号，渠道模型 ID 保持原样。
- 新增按模块设置的参考图识别精度默认值，供支持逐图精度的生图模型使用。

## 局部编辑与保存

- 画笔和减选支持“闭合自动填充”，圈内处理可与整笔一起撤销、重做。
- 改进蒙版画笔响应和结果合成预览；确认保存仍生成原尺寸结果。
- 普通编辑在手动保存、生成前后、切换工程和正常关闭时保存，减少编辑期间的工程写入。
- 未生成的蒙版草稿和未确认的合成试画只保留在当前编辑窗口，离开后不保存；`Ctrl+S` 不保存这些试画。

## 稳定性

- Gemini 与 Images 生图请求等待上限延长至 10 分钟。
- 生图失败诊断保存在本机运行目录，仅保留最近 50 条，不写入工程文件。
- 超时提示区分本地停止等待与上游处理状态，不自动重试或切换模型。

## 下载与升级

- 安装版：`Ediro-0.1.4-windows-x64-setup.exe`。
- 便携版：`Ediro-0.1.4-windows-x64-portable.zip`。关闭旧版后完整解压，保留原有 `data` 文件夹。
- 应用源码：`Ediro-0.1.4-source.zip`。
- 附带安装包 `.blockmap`、更新信息 `latest.yml`、源码引用 `source-reference.json` 和 `SHA256SUMS.txt`。

安装版与便携版继续使用各自的数据目录。旧工程与旧版自定义配置保持读取兼容；预设和自定义指令可通过导出配置备份或迁移。Windows 程序继续采用未签名方式。

## 验证范围

发布检查包括自动化测试、类型检查、构建、隔离的桌面自检、打包内容与源码核对。模拟模型测试不代表真实模型质量；跨版本安装升级和另一台 Windows 电脑的使用效果需独立验收。正式发布时另行检查匿名下载和远端附件完整性。
