# Ediro v0.1.3

本版本加入核心指令与角色指令自定义，并整合参考图处理、自动提示词、模型库和结果管理的改进。

## 指令自定义

- 在设置中的“核心指令”编辑主体、构图、风格、视角，以及通用、陈列师角色指令。
- 支持恢复本项或全部默认、导入和导出。导入先进入草稿，保存并应用后用于后续任务。
- 预览只编译当前编辑项；模块的两种表达分别预览，出厂指令正文不展示。
- 风格模块采用本轮确认的默认指令：参考环境类型、道具、配饰、色调和光线，不沿用参考图的构图、物体位置、比例和空间关系。
- 自定义设置随当前运行环境保存；升级保留用户覆盖，未自定义项跟随版本默认。历史任务和结果不重写。

## 工作流程改进

- 支持 OpenAI 兼容理解接入，简化模型库和模型入库交互。
- 加入两阶段自动提示词、角色选择及默认值保存；提供独立的文字参考模式。
- 增加本地参考图预处理、按模块保存的参考图处理参数与缩放默认值。
- 改进参考图预览、生成进度反馈和结果管理。

## 下载与升级

- 安装版：`Ediro-0.1.3-windows-x64-setup.exe`。升级保留原有用户数据。
- 便携版：`Ediro-0.1.3-windows-x64-portable.zip`。关闭旧版后完整解压，并保留原有 `data` 文件夹。
- 应用源码：`Ediro-0.1.3-source.zip`。
- 附带安装包 `.blockmap`、更新信息 `latest.yml`、源码引用 `source-reference.json` 和 `SHA256SUMS.txt`。
- 第三方源码集独立公开保存，包含精确版本、原始许可、构建材料和核对记录；大型归档按卷提供，下载方法见源码引用。

安装版和便携版设置分别保存在各自的数据目录，切换使用时可手动导入自定义指令。Windows 程序继续采用未签名方式。

## 验证范围

发布候选使用自动化测试、类型检查、构建及隔离的桌面自检验证。模拟模型测试不代表真实模型质量；跨版本安装升级和另一台 Windows 电脑的使用效果需独立验收。正式发布前另行检查对应源码、匿名下载和远端附件完整性。
