# Ediro v0.1.5

修复 Nano Banana 返回可正常解码的图片时，因接口标注的格式与图片实际编码不一致而出现“模型返回图片的格式或尺寸无效”的问题。

## 图片接收与格式设置

- Nano Banana 按实际 PNG、JPEG 或 WebP 编码保存原始图片，文件扩展名与实际格式一致；不再因错误或非标准的格式标签拒收有效图片。
- 主界面和模型默认设置中的输出格式显示“以实际输出为准”，不再提供无法控制请求的 PNG 选项。
- 旧工程中保留的格式参数继续兼容，不会因为该参数而阻挡 Nano Banana 生成。
- GPT Image 等支持输出格式参数的模型继续提供格式选择。
- 保留图片完整解码、实际格式、尺寸和像素上限检查；损坏图片仍会被拒绝。

## 下载与升级

- 安装版：`Ediro-0.1.5-windows-x64-setup.exe`。
- 便携版：`Ediro-0.1.5-windows-x64-portable.zip`。关闭旧版后完整解压，保留并迁移原有 `data` 文件夹。
- 应用源码：`Ediro-0.1.5-source.zip`。
- 附带安装包 `.blockmap`、更新信息 `latest.yml`、源码引用 `source-reference.json` 和 `SHA256SUMS.txt`。

Windows 程序继续采用未签名方式。安装版与便携版继续使用各自的数据目录。

## 验证范围

修复已通过 656 项自动化测试，1 项可选模型权重测试跳过；类型检查、构建和隔离桌面验证通过。桌面验证包括 8 次本地模拟生成，未调用真实模型 API。跨版本安装替换及真实渠道行为未实测。
