# Ediro v0.1.0

Ediro 的第一个公开版本：面向电商视觉设计的 Windows AI 图像工作台。

## 首版包含

- 组合主体、构图、风格、文字和视角参考，内置作者选定的默认模块提示词。
- 生图、局部编辑、结果历史与历史参数恢复。
- 自包含 `.ediro` 工程、自动保存、另存为和项目记录。
- Windows x64 安装版与 ZIP 便携版，均自带运行环境。
- GitHub 新版本检查：安装版确认下载后保存并重启升级；便携版引导下载新版。
- GPL-3.0-only 源码与第三方许可、源码材料。

## 下载文件

| 文件 | 用途 |
| --- | --- |
| `Ediro-0.1.0-windows-x64-setup.exe` | 通常选择此安装版，建议保留默认目录 |
| `Ediro-0.1.0-windows-x64-portable.zip` | 完整解压到可写目录，运行 Ediro.exe |
| `Ediro-0.1.0-source.zip` | 应用源码、默认提示词及构建材料 |
| `Ediro-0.1.0-third-party-sources.zip` | 第三方源码归档、构建配方及许可材料 |
| `SHA256SUMS.txt` | 发布文件校验值 |

`latest.yml` 和安装包同名 `.blockmap` 供更新组件使用，一般用户无需单独下载。

## 开始使用

在设置中配置自己的模型连接、API Key 和默认生图模型，再添加素材、填写要求并生成。真实调用可能收费；模拟模式只用于检查流程。发布包不含作者账号、密钥、工程或私有调优记录。

安装版工程和导出默认放在系统“文档”目录下的 `Ediro`，设置在当前用户目录。便携版数据在程序旁的 `data` 文件夹，更新时请关闭程序并保留整个 `data`。换电脑或 Windows 用户后须重新配置 API Key。

## 当前已知限制

- 当前包未进行代码签名，Windows 可能提示未知发布者。请从本仓库下载并核对校验值。
- 只提供 Windows x64；首版验收在开发者本机完成，尚未覆盖其他电脑。
- 已验证安装版、便携版及工程重开后图片和内容保留。更新状态、下载校验、保存保护完成本地测试；真实 GitHub 跨版本安装升级需在后续版本发布时继续验收。
- 更新需要访问 GitHub；检查失败不影响使用，也可手动下载新版。
- 不同模型与渠道效果不同，默认提示词不能保证所有模型生成相同结果。

使用与构建说明见 [README](https://github.com/SimonFlipig/Ediro#readme)。反馈时请附版本、操作步骤和报错，勿上传 API Key 或不能公开的工程。
