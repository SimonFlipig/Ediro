# Ediro v0.1.2

修复 v0.1.1 中点击“理解／识别”时，误报“历史配方与此接入的模型预设不一致，请重新选择模型”的问题。

理解任务现在使用所选理解模型的预设，不再沿用生图配方的预设标识。支持有预设和无预设的理解接入，原配方与历史结果保持不变，生图任务的历史模型校验继续保留。无需清空或重新配置模型库。

## 下载与升级

- 安装版：`Ediro-0.1.2-windows-x64-setup.exe`。在程序中检查更新，下载完成后选择“保存并重启升级”。
- 便携版：`Ediro-0.1.2-windows-x64-portable.zip`。关闭旧版后完整解压，保留原来的 `data` 文件夹。
- 应用源码：`Ediro-0.1.2-source.zip`。
- 第三方源码与许可材料：`Ediro-0.1.2-third-party-sources.zip`。
- 附带 `SHA256SUMS.txt`、安装包 `.blockmap` 和更新信息 `latest.yml`。

安装版升级保留原有用户数据。Windows 包继续使用与前版相同的未签名方式。

## 验证范围

新增回归测试复现并覆盖此次预设误拦截；理解任务、历史模型恢复与执行计划共 27 项相关测试通过，类型检查与构建通过。验证使用本地模拟响应，没有调用付费模型；安装版升级后的真实理解效果仍需用户实测。
