# Ediro v0.1.1

本次更新改善模型库操作，并修复首版的导出恢复、历史模型识别和工程保存问题。

## 模型库

- 三栏联动：左侧选择平台，中间选择模型，右侧直接调整设置。
- 默认参数与接入设置分开显示，保留预设能力、渠道兼容参数和默认模型指派。
- 平台配置与模型入库改为独立页面，不再叠加抽屉；新平台保存后直接进入入库。
- 支持按预设匹配批量入库和手动添加平台别名；成功后回到列表并选中新模型。
- 切换模型、平台或返回工作台时，保护尚未保存的修改。

## 修复

- 导出图片恢复使用 `Ediro_…` 命名；支持从本机索引恢复旧产出，拖回图片可恢复对应版本。
- 历史工程中的模型配置与本机不一致时，按模型预设和可用接入匹配；保留历史快照。
- “另存为”支持确认后覆盖已有工程，另存到当前文件等同普通保存；覆盖失败保留目标原文。

## 下载与升级

- 安装版：`Ediro-0.1.1-windows-x64-setup.exe`。v0.1.0 用户可在程序内检查更新，下载后选择“保存并重启升级”。
- 便携版：`Ediro-0.1.1-windows-x64-portable.zip`。关闭旧版后完整解压，保留原来的 `data` 文件夹。
- 应用源码：`Ediro-0.1.1-source.zip`。
- 第三方源码与许可材料：`Ediro-0.1.1-third-party-sources.zip`。
- 附带 `SHA256SUMS.txt`、安装包 `.blockmap` 和更新信息 `latest.yml`。

安装版升级继续使用原有用户数据目录，无需清空模型库。发布包不包含开发者密钥、工程或私有调优数据。当前 Windows 包未进行代码签名，与首版一致。

## 验证范围

构建、249 项回归测试及隔离桌面交互验证通过。桌面验证覆盖三栏切换、未保存保护、默认编辑模型、批量入库失败后的重试与手动别名入库，不调用付费模型。跨版本在线升级以发布后的安装版实测为准。
