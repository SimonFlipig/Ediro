# Ediro · AI 图像工作台

面向电商视觉设计的 Windows 桌面工具：组合主体、构图、风格、文字要求和视角参考，生成图片，并在同一工程中继续局部修改和管理历史版本。

Ediro 独立运行，不依赖 Codex 或其他工作台。真实生成需要自行配置模型连接与 API Key；模拟引擎可以免费检查工作流程，不代表真实模型效果。

## 获取与启动

目标平台为 **Windows x64**。在 [GitHub Releases](https://github.com/SimonFlipig/Ediro/releases) 获取发布版本，首版变更见 [v0.1.0 发布说明](docs/RELEASE_NOTES_v0.1.0.md)：

- **安装版**：下载 `Ediro-<版本>-windows-x64-setup.exe`，安装后从桌面或开始菜单启动。一般保留当前用户的默认安装目录；如需安装到 `Program Files`，请选择为所有用户安装并允许管理员权限请求。
- **便携版**：下载 `Ediro-<版本>-windows-x64-portable.zip`，完整解压到可写文件夹，运行其中的 `Ediro.exe`，不要直接在压缩包内运行。

两种版本都包含运行环境，使用者不需要安装 Node.js。当前发布包未签名，Windows 可能显示未知发布者提示。校验文件随包提供，请核对来源和校验值。

## 开始一次创作

1. 在“设置”中配置连接、API Key 和模型，选择默认生图模型。模型测试和真实生成可能计费。
2. 启动后进入空白工作台。拖入图片，或点击“添加素材”。
3. 将图片放入主体、构图、风格等参考模块，填写要求；也可以使用自由图文、提示词和视角模块。
4. 选择模型和参数，发起生成。真实模型失败后不会自动重试或切换平台。
5. 选择历史结果可恢复该版本的创作参数；需要修改时进入局部编辑。完成后导出普通图片。

默认包含作者选定的模块提示词配置。模型能力、输入图片和用户要求仍会影响结果，不保证所有模型产生相同效果。

## 保存与继续工作

- `.ediro` 是自包含工程，保存素材、结果、创作参数、历史及恢复记录。
- 启动或“新工作”先进入空白状态；首次成功加入素材或有效生成入队时创建默认工程。显式“另存为”也可以保存空白工作。
- 普通编辑停顿约 2 秒后自动保存；`Ctrl+S` 可立即保存。切换和正常关闭前补存，保存失败会保留窗口并提示。
- 打开已有 `.ediro` 直接编辑该文件；“另存为”创建独立副本并切换，保留原工程。
- 重启后通过“项目记录”或拖入 `.ediro` 继续，不会自动打开上次工程。
- 导出图片与工程独立，继续编辑需保留 `.ediro`。工程删除使用回收站，导出图片和其他工程保留。

强制结束或断电可能丢失尚未写入的最新编辑。请在正常保存并关闭后复制工程，不要在保存过程中移动文件。

## 数据在哪里

| 版本 | 默认工程与导出 | 设置、凭据与恢复缓存 |
| --- | --- | --- |
| 安装版 | 系统“文档”目录下 `Ediro/Project`、`Ediro/output` | `%APPDATA%/Ediro/runtime` |
| 便携版 | 程序旁 `data/Project`、`data/output` | `data/.local/runtime` |
| 源码开发版 | 源码根目录 `Project`、`output` | `.local/runtime` |

打开或另存到其他位置的工程会继续在所选路径保存。升级便携版前关闭程序，完整保留 `data` 并放到新版 EXE 旁；保留 `ediro-portable.json` 模式标记。安装版卸载不主动删除工程和设置。

API Key 使用系统安全存储加密，不进入工程。换电脑或 Windows 用户后须重新配置连接和凭据。素材、提示词和历史请求属于工程内容，分享工程前请确认可以分享这些内容。

## 当前边界

- 图片导入支持 PNG、JPEG、WebP；数量、尺寸和参数还受所选模型及渠道限制。
- 首版不包含系统级 `.ediro` 文件关联或跨进程实时协作。
- 大工程需要额外磁盘空间用于工作缓存，详情见 [单文件工程](docs/单文件工程_v1.md)。
- 本地回归与模拟测试不能替代真实模型质量测试；真实调用需自行承担 API 费用。

## 软件更新

发布版启动后及运行期间定时检查 GitHub 上的正式版本，也可点击顶部“检查更新”。需要能正常访问 GitHub；检查失败不影响继续工作。

- 安装版：点击下载，校验完成后点击“保存并重启升级”。生成、推理或模型测试未结束、编辑未保存或保存失败时，不会启动升级。关闭程序不会擅自安装已下载的更新。
- 便携版：提示新版并打开对应发布页；下载便携 ZIP，完整解压到新目录，关闭旧程序后保留并迁移 `data` 文件夹。
- 更新保留用户工程和设置；安装到 Program Files 时，Windows 可能再次请求管理员权限。
- 源码开发模式不检查或自动替换文件。更新只跟随正式发布版本，不跟随普通代码提交。

目前更新包未配置代码签名，下载通过 HTTPS 并核对发布元数据中的 SHA-512；这不等同于发布者数字签名。

## 从源码运行与构建

需要 Windows、Node.js 22.12 或以上版本及 npm。

```powershell
npm ci
npm run dev
```

```powershell
npm run check
npm run package:win
```

`check` 执行应用类型检查、运行测试及构建；测试源码的独立严格类型检查暂未纳入。`package:win` 在 Windows x64 上生成候选安装包和便携 ZIP，不上传远端。详情见 [Windows 发布与数据目录](docs/Windows发布与数据目录.md)。

源码目录的 `Ediro.vbs`、`启动 Ediro.cmd` 会检查构建状态并启动开发目录的程序，首次使用仍需安装依赖。开发启动日志在 `.local/launcher/build.log`。
